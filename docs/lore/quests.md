# Квесты (контент для волны G8)

Спецификация квестов по канону. Код-волна G8 берёт эти данные и делает систему
квестов (источник → выдача → прогресс → награда). Здесь — только содержание.

## Источники квестов

- **Гильдии** (`guild`) — контракты: зачистка, сопровождение, охота за головами.
- **Таверны** (`tavern`) — слухи и мелкие поручения; дешёвые, но открывают карту.
- **Храмы** (`temple`) — милосердие, реликвии, ритуалы.
- **Библиотеки** (`library`) — исследования: найти запись, восстановить имя.
- **Обычные NPC** — личные просьбы, привязаны к характеру (plus/minus).

Каждый квест имеет: `key`, `source` (тип), `giver` (ключ NPC или здание),
`chapter`, `title`, `text`, `objective` (тип + цель), `reward`
(`gold`, `xp`, `item`, `opinion`), `requires` (предыдущие ключи).

## Главы 4–7 — по 5–8 квестов каждая

Квесты глав 4–7 пишутся по тем же полям и привязываются к континентам:
Колыбель (заморозка/оттепель), Кор-Ашан (купить/заложить память), Гавани
(флот, клан), Лес (разбудить мир). Их содержание добавляется в эту таблицу по
мере открытия континентов (G5).

## Типы целей (`objective.type`)

- `kill` — убить N указанных монстров.
- `visit` — посетить локацию.
- `collect` — собрать N предметов.
- `deliver` — отнести предмет NPC.
- `talk` — поговорить с NPC (диалог-тема).
- `survive` — выжить N ходов в бою.
- `revive` — воскресить спутника ритуалом.
- `no_steel` — пройти бой без оружия (для друида).

## Награды (`reward`)

- `gold` — золото (учитывает DEFEAT_GOLD_PENALTY отдельно).
- `xp` — опыт.
- `item` — ключ предмета из ITEMS (G2).
- `opinion` — Δ мнения NPC-выдающего.
- `unlock` — флаг прогресса (локация/глава).

## Прогресс и главы

- Квесты хранят `chapter`; кампания (G11) проверяет флаги глав.
- Ключевые квесты (`prologue_name`, `first_revival`, `bone_records`,
  `spire_permission`) — сюжетные, их нельзя провалить навсегда: при провале
  возвращаются в выдачу.
- Побочные — можно провалить; выдающий меняет мнение (обычно −5).

## Тон текстов

- Короткие, мрачные, без пафоса. Пример: «Кто-то снял с мертвеца сапоги и
  оставил ему имя. Верни имя — сапоги оставь себе.»
- Награда формулируется через память, а не через «славу»: «тебя запомнят»,
  «имя вернётся в книгу».
