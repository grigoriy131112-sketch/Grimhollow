# Онлайн (контент для волны G12 — последняя)

По директиве G12 идёт **последней**. Здесь — только рамки, чтобы волна не
противоречила канону и не сломала офлайн-игру.

## Принцип

Гримхоллоу — одиночная игра. Онлайн не должен требовать его для прохождения и
не должен превращать мир в MMO. Всё, что добавляется, — **асинхронное и
необязательное**.

## Что допустимо

1. **Призраки-летописцы.** Другие игроки оставляют в мире «имена» — короткие
   надписи у локаций (могильные камни, фонари). Их видно, но они не влияют на
   баланс. По канону это буквально «кто-то помнит»: мир делится памятью.
2. **Обмен телами.** Можно выложить и скачать «тело» павшего спутника (снимок
   G4) — чтобы другой игрок вывел его из царства мёртвых. Асинхронная помощь.
3. **Списки имён.** Глобальная книга: сколько имён вернули игроки суммарно;
   счётчик без рейтинга и без наград за первое место.
4. **Ежедневная «оттепель».** Общий для всех ивент-модификатор (погода
   забвения), одинаковый на день; не PvP.

## Что запрещено

- PvP и рейтинги (ломают тон и баланс).
- Обязательная авторизация для одиночной игры.
- Реальная торговля, донаты, лутбоксы.
- Чат в реальном времени (тон мира — тишина и память, не гомон).

## Реализация (когда дойдём)

- Отдельный сервис `server/src/services/online.js` + лёгкий store; офлайн-режим
  работает без него (graceful degradation).
- Все сетевые данные — текст, не влияет на бой.
- Модерация имён-надписей: фильтр + репорты.

## Тон

- Онлайн — это «эхо других», а не «другие игроки». Ты видишь, что кто-то был
  здесь и помнил; этого достаточно.
